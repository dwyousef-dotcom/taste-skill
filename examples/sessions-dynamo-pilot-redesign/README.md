# sessions-dynamo.com/pilot redesign

A single-file redesign of https://sessions-dynamo.com/pilot built with the
`taste-skill` (redesign-overhaul mode: dials 5/4/4, forest palette,
Bricolage Grotesque + Instrument Sans + IBM Plex Mono, fonts embedded as
data URIs so the file is fully self-contained).

## View it locally

```sh
cd examples/sessions-dynamo-pilot-redesign
python3 -m http.server 4173
```

Then open http://localhost:4173 in your browser. No build step, no
dependencies, works offline.
